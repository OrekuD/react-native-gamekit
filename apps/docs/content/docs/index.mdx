React Native Gamekit is a headless-first 2D game toolkit for React Native and
Expo, built for mobile and tablet.

The product boundary:

- **Mobile and tablet.** Phones, iPad, Android tablets — including rotation,
  split view, and resizable windows.
- **Expo and React Native.** Development builds via `expo prebuild`; Expo Go is
  not a supported requirement.
- **Excellent 2D first.** A stable, well-tested 2D experience is the priority;
  the architecture keeps seams open for future 3D work.

## Headless-first

React props configure or observe a game session; they never become the
per-frame store. Game state advances through a headless session, not through
React re-renders.

## Getting started

Start with [Installation](getting-started/installation) to set up a
development build, then [Create Your First Game](getting-started/create-your-first-game)
to define and render a small interactive 2D scene. Afterwards, [Next steps](getting-started/next-steps)
maps the rest of the docs, and the [Game Definition](core-concepts/game)
concept covers the full provisional `defineGame` contract.
