---
title: Sprites
description: Render retained sprites and sprite-sheet frames with React Native Gamekit.
---

A `Sprite` renders one full-image asset or one sprite-sheet frame through a
source-verified Skia path. Every animatable property accepts plain numbers or
Reanimated shared/derived values — nothing is mirrored through React state,
and the sprite never subscribes React to the game frame.

## The world group

`GameWorld2D` applies the resolved viewport offset and scale exactly once to
all children. It is not a camera API; raw Skia nodes can be nested freely.

```tsx
import { GameWorld2D, Sprite } from 'rn-gamekit/react';

function MyRenderer({ frame, alpha, viewport, assets }) {
  if (assets === undefined) return null;
  return (
    <GameWorld2D viewport={viewport}>
      <Sprite source={assets.get(gameAssets.gameplay.player)} frame="idle-0" x={160} y={300} />
    </GameWorld2D>
  );
}
```

## Properties

| Prop | Meaning |
| --- | --- |
| `x`, `y` | World position in logical units (number or animated value). |
| `rotation` | Radians around the anchor (number or animated value). |
| `scale` | Uniform scale around the anchor (number or animated value). |
| `anchor` | Normalized `[0, 1]` relative to the selected frame; `(0, 0)` is top-left, `(0.5, 0.5)` is centre. |
| `flipX`, `flipY` | Explicit flips that preserve the anchor. |
| `opacity` | In `[0, 1]`; hiding is expressed as a combined opacity so the component stays mounted. |
| `tint` | Optional tint color. |
| `sampling` | Pixel-art defaults to nearest-neighbour. |
| `frame` | The sheet frame name; overrides `clip`. Plain string or shared string, optionally carrying `undefined` before publication. |
| `clip`, `elapsedMs` | Clip name and elapsed milliseconds. A shared clip may carry `undefined` before publication. |

The transform pipeline is documented and tested as pure code:

```
T(x, y) · R(rotation) · S(scaleX, scaleY) · T(-pivot)
```

Here `pivot = (anchor.x * frame.width, anchor.y * frame.height)`,
`scaleX = scale * (flipX ? -1 : 1)`, and similarly for `scaleY`. The local
pivot lands at world `(x, y)` for every scale, rotation, and flip. The Atlas
RSXform carries uniform scale/rotation/placement; the outer Group handles
reflection. Reflection needs only position, rotation, and flips, so it does
not resample the animation or depend on its frame dimensions.

Both full images and sheet frames use a single-entry Atlas. The `scale` prop
is uniform; there is no separate `scaleX`/`scaleY` prop.

## Unpublished selection

For a direct Sprite whose clip arrives later, keep absence explicit:

```tsx
const clip = useSharedValue<string | undefined>(undefined);
return <Sprite source={player} clip={clip} elapsedMs={elapsedMs} />;
```

The sheet draws nothing until a clip is published. An empty string is an invalid
clip name, not an absence marker. `SpriteAnimatableString` is exported from
`rn-gamekit/react` alongside the number/boolean aliases; it describes a string
or `SharedValue<string>`. The `frame` and `clip` props additionally accept
`SharedValue<string | undefined>`.

`resolveSpriteFrameRect(source, undefined)` retains its legacy static-baseline
behavior: it returns the first animation's first own frame, or an empty rectangle.
This helper does not describe the renderer's absent-selection behavior.

## GameSprite: the common path

`GameSprite` accepts the renderer's `commit`/`alpha` values, narrows the
snapshot by scene, and invokes one worklet selector — no author-written
`useDerivedValue` or Skia plumbing:

```tsx
<GameSprite
  scene="play"
  commit={frame}
  alpha={alpha}
  source={assets.get(gameAssets.gameplay.player)}
  anchor={{ x: 0.5, y: 1 }}
  select={({ previous, current, alpha: t }) => {
    'worklet';
    return {
      x: previous.playerX + (current.playerX - previous.playerX) * t,
      y: current.playerY,
      clip: current.animation.clip,
      elapsedMs: current.animation.elapsedMs,
      flipX: current.facing === 'left',
    };
  }}
/>
```

Position, rotation, uniform scale, and opacity interpolate when the selector
requests it; clip/frame, visibility, and flips are chosen discretely
from the committed snapshot. The selector's scene typing is exact — a
`scene="play"` selector receives only the play snapshot without casts.

## Drawing order

React child order is the drawing order for retained sprites. A general
layer/render graph is deferred. An unknown frame name throws; only explicitly
declared frame entries count, including names that also occur on Object.prototype.
Keep the asset lease alive while any Sprite/GameSprite uses its image. These
components borrow native handles and cannot detect every use after lease disposal.
