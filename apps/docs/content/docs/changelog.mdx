## Unreleased (current main)

- Package entry points: `rn-gamekit/geometry`, `rn-gamekit/collision2d`, `rn-gamekit/camera2d`, `rn-gamekit/events`, `rn-gamekit/assets`, and `rn-gamekit/sprites` are now explicit subpaths of the single `rn-gamekit` package — one `npm install`, one version, one `exports` map. Existing root imports remain valid (same symbols, no duplicate state); the new subpaths are the preferred organization.
- Camera2D: one authoritative presented camera shared by rendering and pointer input, with follow, world bounds, cuts, deterministic shake, parallax layers, and visibility culling.
- Typed game events: declared event names, typed envelopes with payload limits, deterministic seeding, and update-scoped emitters.
- Particles: headless effect simulation with presentation-only Skia rendering and camera-aware culling.
- Optional audio (`rn-gamekit/audio`) and haptics (`rn-gamekit/haptics`) subpath entries with lifecycle-aware playback and bounded presets.
- Tilemaps and storage: chunked tile worlds with platformer movement and `TileMapLayer2D`; versioned `rn-gamekit/storage` with `defineGameSave` / `createGameSaveStore`, `createMemoryStorageAdapter` and optional `createGameStorageAdapter` (`@react-native-async-storage/async-storage`), per-slot ordering, `flush()` / `dispose()`, migrations, and `GameStorageError`.
- `useGameSession(definition)` from `rn-gamekit/react`: React-owned session creation and terminal disposal, Strict Mode safe, with exact scene/input type inference.
- Observable pause/resume lifecycle: `GameSession.addStatusListener()` and `useGameSessionStatus()`.
- Paused-input policy: gameplay input is cancelled on pause and rejected while paused.
- Collision2D: geometry primitives, contacts, exact Minkowski sweeps, colliders, filters, broad phase, and headless debug projection.

## 0.1.0

The first published release: the headless session runtime, fixed-step loop, pointer and button input, viewport math, sprites and sprite batches, asset manifests, the React adapter (`GameView`, hooks), and the Brick Breaker reference game.
