title: Supported platforms

react native gamekit targets phones and tablets running Expo SDK 57. The playground exercises the full toolkit on iOS, iPadOS, and Android, including rotation, resize, and iPad split view.

## Platforms

- iOS and iPadOS, tablet enabled, both orientations
- Android phones and tablets

## Development builds, not Expo Go

Expo Go can't run this. The toolkit needs the Skia, Gesture Handler, and Reanimated runtimes, which are native modules, so you need a development build generated with `expo prebuild`. That's the workflow the playground itself uses.

## The validated compatibility line

The exact native workspace pins and the library's supported peer ranges are
separate. Audio, haptics, and persistent storage peers are optional. Upgrades
require native builds and smoke checks; this table alone is not a device
validation report.

## Native singletons

Skia, Gesture Handler, Reanimated, Worklets, and Expo Asset are native peers. Your app owns one compatible copy of each, and react native gamekit declares the exact line it was validated against. Applications must contain exactly one copy of every native peer.
