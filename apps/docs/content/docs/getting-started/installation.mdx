# Installation

React Native GameKit is consumed from the `react-native-gamekit` package. The
playground uses **local native development builds** — Expo Go is not a
supported requirement.

## Requirements

- Node.js `>=22.13.0`
- pnpm 11

## Install in an application

```sh
npm install react-native-gamekit
npx expo install expo-asset @shopify/react-native-skia react-native-gesture-handler react-native-reanimated react-native-worklets
npx expo prebuild
```

Wrap the application root in `GestureHandlerRootView`. Native libraries are
peer dependencies: the application owns one compatible copy of each while
GameKit declares the exact compatibility line it was validated against.

## Install the workspace

```sh
git clone https://github.com/OrekuD/react-native-gamekit.git
cd react-native-gamekit
pnpm install
```

## Generate native projects

The `ios` and `android` directories are produced by Expo Continuous Native
Generation (CNG). They are never committed — change native configuration
through `app.json` and config plugins only.

```sh
pnpm expo:prebuild
```

Regenerate from a clean state with:

```sh
pnpm expo:prebuild:clean
```

## Run the playground

```sh
pnpm ios       # iOS / iPadOS simulator
pnpm android   # Android emulator
```

The playground includes shape, Brick Breaker, sprite-sheet animation, asset
loading, batching, and performance examples. It also covers rotation, resize,
and iPad split-view behavior.

## Package consumers

For a regular app, the package declares `react`, `react-native`, `expo`,
`expo-asset`, Skia, Gesture Handler, Reanimated, and Worklets as peers. Your
application must contain exactly one compatible copy of every native peer.
