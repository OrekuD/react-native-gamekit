You'll need an Expo project and a few minutes. By the end of this page you'll have a native dev build running React Native Gamekit, ready for your first scene.

## Requirements

Use an Expo SDK 57 project. The table distinguishes the exact native workspace
versions from supported consumer ranges. Audio, haptics, and persistent storage
peers are optional.

{/* deps:table:start */}
| Package | Workspace version | Supported peer range |
| --- | --- | --- |
| `@react-native-async-storage/async-storage` | `2.2.0` | `^2.2.0` |
| `@shopify/react-native-skia` | `2.11.0` | `2.11.0` |
| `expo` | `57.0.25` | `~57.0.25` |
| `expo-asset` | `57.0.18` | `~57.0.18` |
| `react` | `19.2.3` | `^19.2.3` |
| `react-native` | `0.86.3` | `~0.86.3` |
| `react-native-audio-api` | `0.13.3` | `^0.13.3` |
| `react-native-gesture-handler` | `3.1.0` | `~3.1.0` |
| `react-native-pulsar` | `1.7.0` | `^1.7.0` |
| `react-native-reanimated` | `4.5.3` | `4.5.3` |

## Install the native peers

Gamekit doesn't ship native code. Skia, Gesture Handler, Reanimated, Worklets, and Expo Asset are native modules that your app owns, and Gamekit declares the exact version line it was validated against. Your app ends up with exactly one copy of each native module, which is what native modules want.

Pin the validated line so you don't drift to the SDK template versions:

{/* deps:install:start */}
<Tabs items={['npm', 'yarn', 'pnpm', 'bun']} groupId="package-manager" persist>
  <Tab value="npm">
    ```sh
    npx expo install @shopify/react-native-skia@2.11.0 expo-asset@57.0.18 react-native-gesture-handler@3.1.0 react-native-reanimated@4.5.3 react-native-worklets@0.10.3
    ```
  </Tab>
  <Tab value="yarn">
    ```sh
    yarn expo install @shopify/react-native-skia@2.11.0 expo-asset@57.0.18 react-native-gesture-handler@3.1.0 react-native-reanimated@4.5.3 react-native-worklets@0.10.3
    ```
  </Tab>
  <Tab value="pnpm">
    ```sh
    pnpm exec expo install @shopify/react-native-skia@2.11.0 expo-asset@57.0.18 react-native-gesture-handler@3.1.0 react-native-reanimated@4.5.3 react-native-worklets@0.10.3
    ```
  </Tab>
  <Tab value="bun">
    ```sh
    bunx expo install @shopify/react-native-skia@2.11.0 expo-asset@57.0.18 react-native-gesture-handler@3.1.0 react-native-reanimated@4.5.3 react-native-worklets@0.10.3
    ```
  </Tab>
</Tabs>
{/* deps:install:end */}

Skia, Gesture Handler, Reanimated, and Worklets use GameKit's selected native
versions rather than Expo's defaults. Merge these exclusions into your
`package.json` and review compatibility before changing them or running
`expo install --fix`. See the [Expo package.json reference](https://docs.expo.dev/versions/latest/config/package-json/#installexclude).

{/* deps:excludes:start */}
```json
{
  "expo": {
    "install": {
      "exclude": [
        "@shopify/react-native-skia",
        "react-native-gesture-handler",
        "react-native-reanimated",
        "react-native-worklets"
      ]
    }
  }
}
```
{/* deps:excludes:end */}

Importing `rn-gamekit` does not load these backends. Calling `createGameAudio()` or `createGameHaptics()` without the peer throws `is not installed — run npx expo install ...`.

### Optional persistent storage peer

The memory storage adapter has no native dependency. Install AsyncStorage only
if you use `createGameStorageAdapter()` for persistent saves:

{/* deps:storage:start */}
```sh
npx expo install @react-native-async-storage/async-storage@2.2.0
```
{/* deps:storage:end */}

> The peer versions in your `package.json` need to match the validated line in the table above. If you're upgrading an existing project, check the [Supported platforms](../introduction/supported-platforms) page before you bump anything.

## Generate the native projects

Expo Go can't run this. Gamekit needs the Skia, Gesture Handler, and Reanimated runtimes, which are native modules, so you need a development build. Generate the iOS and Android projects with:

```sh
npx expo prebuild
```

The `ios` and `android` folders are generated, so keep them out of version control. Change native configuration through `app.json` and config plugins, then regenerate. Expo calls this Continuous Native Generation (CNG), and it's the workflow the playground itself uses.

## Wrap the app root

Gesture Handler needs the root of your component tree wrapped in `GestureHandlerRootView`:

```tsx
import { GestureHandlerRootView } from 'react-native-gesture-handler';

export default function App() {
  return (
    <GestureHandlerRootView style={{ flex: 1 }}>
      {/* your game goes here */}
    </GestureHandlerRootView>
  );
}
```

## Run the dev build

```sh
npx expo run:ios     # iOS simulator
npx expo run:android # Android emulator
```

The first build compiles the native modules, so give it a few minutes. Later builds are fast.
