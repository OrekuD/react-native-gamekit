All components below come from the `rn-gamekit/react` entry. The [Components](../react/components) concept explains how they fit together; this page is the reference list.

## Game surface

| Export | Purpose |
| --- | --- |
| `GameView` | Presentation surface: borrows the session, starts on mount, pauses on background, hands `frame`/`alpha`/`viewport` shared values to the renderer. |
| `GamePointerInput` | Touch adapter for one declared pointer action: ownership, cancellation, coalescing. |
| `GameButtonPad` | Multitouch button surface: maps every active pointer to measured `GameButton` zones and flows press and release edges into declared button actions. Full-surface overlay with `pointerEvents="box-none"`; position buttons anywhere with ordinary styles and render any React children underneath. |
| `GameButton` | One touch zone of `GameButtonPad`. Its measured bounds become the hit area for `action`. Must be rendered inside `GameButtonPad`. |
| `ButtonActionName<TInput>` | Type helper that extracts declared button action names from `TInput`. |

## Sprites

| Export | Purpose |
| --- | --- |
| `GameSprite` | Snapshot-driven sprite; a `select` worklet picks the clip and position from game state. |
| `Sprite` | Retained sprite: one full image or one sheet frame, plain or shared-value props. |
| `SpriteBatch` | Many instances of one decoded sheet in one Skia `Atlas` draw, fixed-capacity buffers. |
| `GameWorld2D` | Applies the viewport transform to its children. |

Related helpers: `resolveSpriteFrameRect`, `spriteFrameNameForClip`, `viewportTransform`, `computeSpriteRsxform`, `spriteAnchorWorld`, `spriteGroupCorrection`.

## Camera and layers

| Export | Purpose |
| --- | --- |
| `defineGameCamera2D(select)` | Declares the `GameView`-owned presented camera; the selection runs on commits as a worklet. Passed to `GameView` through its `camera2D` prop. |
| `GameLayer2D` | An ordered parallax layer inside `GameWorld2D`. JSX order is draw order; parallax scales only the camera center contribution. |
| `cameraViewportTransform2D` / `layerParallaxTransform2D` | The composed camera + viewport transform element lists used by the groups. |

See [Camera2D](../engine-systems/camera2d) and [Render layers](../guides/render-layers).

## Particles

| Export | Purpose |
| --- | --- |
| `ParticleView` | Presentation-only Skia surface that draws a headless particle system. |
| `useParticlePresentation` | Binds a particle system to UI-owned buffers for `ParticleView`. |
| `particleSpriteXform`, `assertUniformParticleSpriteRatio` | Sprite transforms for particle rendering. |
| `cameraVisibleWorldBounds`, `visibleInBounds` | Camera-aware culling helpers (`PARTICLE_CULL_PADDING`). |

See [Particles](../engine-systems/particles).

## Asset plumbing

| Export | Purpose |
| --- | --- |
| `createGameAssetStore` | Skia-backed asset store factory (decodes images for the UI runtime). |
| `createGameAssetStoreCore` | Native-independent store core for tests and tooling. |

Related types: `AcquireOptions`, `AssetPipelines`, `GameAssetStore`, `NativeImageHandle`.

## Renderer props

| Export | Purpose |
| --- | --- |
| `GameRendererProps` | The `frame`/`alpha`/`viewport`/`assets` props every renderer receives. |
| `GameViewProps` | The props `GameView` accepts. |
| `GameViewInstrumentation`, `GamePointerInstrumentation` | Diagnostics seams for tests and profiling. |

See [Custom renderers](../advanced/custom-renderers) for the renderer contract and [Instrumentation](../advanced/profiling) for the diagnostics hooks.
